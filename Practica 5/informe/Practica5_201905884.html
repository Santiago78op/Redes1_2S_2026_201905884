En el escenario 1 el único enlace troncal es el que une SW1-L2 (G0/1) con el router (G0/0): por ahí viajan las tramas de ambas VLANs etiquetadas con 802.1Q. En el escenario 2 no hace falta troncal, porque el enrutamiento ocurre dentro del mismo switch al que están conectadas las PCs.

2. Escenario 1 — Router-on-a-Stick

2.1 Switch SW1-L2 (2960)

vlan 10

vlan 20

interface FastEthernet0/1
 switchport mode access
 switchport access vlan 10
interface FastEthernet0/2
 switchport mode access
 switchport access vlan 20
interface GigabitEthernet0/1
 switchport mode trunk
 switchport trunk allowed vlan 10,20

El 2960 solo soporta 802.1Q, por lo que no lleva switchport trunk encapsulation. La troncal se limita a las VLANs 10 y 20.

2.2 Router R1-ROAS (2911)

interface GigabitEthernet0/0
 no ip address
 no shutdown
interface GigabitEthernet0/0.10
 encapsulation dot1Q 10
 ip address 192.168.10.1 255.255.255.0
interface GigabitEthernet0/0.20
 encapsulation dot1Q 20
 ip address 192.168.20.1 255.255.255.0

La interfaz física no lleva IP; solo se levanta con no shutdown, y las subinterfaces heredan ese estado. encapsulation dot1Q N le dice a cada subinterfaz qué etiqueta de VLAN acepta y con cuál marca las tramas que devuelve al switch.

3. Escenario 2 — Switch de Capa 3 (SVI)

vlan 10
 name Marketing
vlan 20
 name Engineering
interface GigabitEthernet1/0/1
 switchport mode access
 switchport access vlan 10
interface GigabitEthernet1/0/2
 switchport mode access
 switchport access vlan 20
interface Vlan10
 ip address 172.16.10.1 255.255.255.0
 no shutdown
interface Vlan20
 ip address 172.16.20.1 255.255.255.0
 no shutdown
ip routing

Cada SVI es una interfaz lógica que representa a toda su VLAN dentro del switch, y sirve como gateway de los hosts de esa VLAN. Una SVI solo se pone up/up si la VLAN existe y tiene al menos un puerto activo asignado. Sin ip routing el 3650 tendría las dos IPs, pero no reenviaría paquetes de una VLAN a otra.

4. Tablas de enrutamiento

En los dos gateways las rutas aparecen como C (conectadas) y L (local, la /32 de la propia interfaz). No hacen falta rutas estáticas ni protocolos dinámicos, porque ambas redes están directamente conectadas al mismo dispositivo. La diferencia es la interfaz de salida: en el router son subinterfaces de un único puerto físico, y en el switch son interfaces virtuales.

El TTL de las respuestas es 127, y no 128: el paquete atravesó exactamente un dispositivo de capa 3, que es el gateway. El tracert lo confirma, porque el primer salto es la IP del gateway de la VLAN de origen. El primer ping después de encender la red pierde paquetes mientras se resuelve ARP (PC → gateway y gateway → PC destino); los siguientes salen 4/4.
